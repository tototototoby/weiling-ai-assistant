# 扫码领取你的微Link

这篇教程给产品体验者和团队成员使用。它不需要用户先安装微Link客户端；部署者要先完成 Web、Bot 和通道配置。

## 预期结果

打开一条分享链接，扫码领取或绑定一个可用 Bot，然后在自己的聊天入口发出第一条消息。

## 前置条件

- 管理员已经创建 Bot 并启用二维码分享；
- Bot 处于可登录或等待扫码状态；
- 测试手机安装了对应聊天客户端；
- 分享链接使用 HTTPS，且没有把内部管理地址暴露给外部用户。

## 步骤

1. 管理员在 Bot 详情页创建分享链接。
2. 复制分享地址，用浏览器或聊天窗口打开。
3. 查看页面显示的 Bot 名称和有效期；不要在公开群里粘贴真实登录二维码截图。
4. 使用手机扫码，并按平台提示确认领取。
5. 等待页面跳转到成功状态或显示下一步。
6. 在绑定的聊天入口发送：

   ```text
   你好，先告诉我你现在能做什么，不要调用外部工具。
   ```

7. 如果没有回复，记录分享链接版本、Bot 状态和脱敏日志，交给管理员处理，不要连续重复扫码。

## 管理员验收

- 分享链接过期后无法继续领取；
- 新用户只能看到自己的 Bot/工作区；
- 关闭分享或删除 Bot 后，旧链接不再产生新的绑定；
- 页面不会显示数据库路径、内部端口、邮箱白名单或通道 Secret；
- 日志不会打印完整二维码 URL、Cookie 或 Token。

## 脱敏说明

公开教程和截图使用失效占位二维码。真实二维码可能含一次性登录/绑定凭据，发布前在另一台设备验证它不能再登录。链接、聊天截图和演示视频都不要包含手机号、邮箱、客户名、内网域名或用户文件名。

## 排障

| 现象 | 建议 |
| --- | --- |
| 分享页打不开 | 检查 `APP_BASE_URL`、反向代理、证书和分享 token 是否过期。 |
| 能打开但没有二维码 | 检查 Bot 是否启动、通道是否授权、Supervisor 是否连接。 |
| 扫码后仍在等待 | 等待状态刷新；检查手机网络和通道日志。 |
| 领取了别人的 Bot | 立即停止使用并通知管理员检查绑定、链接有效期和身份路由。 |
