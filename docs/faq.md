# FAQ

## 用户需要安装一个新的客户端吗？

不需要。用户可以从已经在用的聊天入口或网页开始；部署者仍要安装并维护 Web、Supervisor、模型和通道依赖。

## 电脑关机后，任务还能继续吗？

适合托管的任务在服务端的 Supervisor 和沙箱中运行，因此不依赖用户的工作电脑一直开机。若你把 Bot 运行在本地进程、使用 disabled 沙箱或关闭了服务器，任务仍可能暂停。

## 微信、企业微信和飞书一定能同时用吗？

项目提供三种通道的接入路径，但每个平台都需要自己的账号、应用、授权、网络和版本。只有完成真实端到端验证后，才把某个通道标为可用。共享上下文需要两个入口绑定到同一个 Bot，不是只安装三个 SDK。

## 微信两天没聊天后还能主动发消息吗？

不能保证。微信 iLink/登录态的主动消息可能受平台侧时间窗或策略限制。微Link可以保留任务、继续执行并记录投递失败；重要提醒可以配置企业微信或飞书作为补充，但也不能绕过它们各自的政策。

## 一台服务器可以给多人用吗？

设计上支持多用户、多个 Bot 和按用户/Bot 划分的实例/沙箱。部署者仍需使用邀请码、最小权限、独立密钥和生产加固；当前版本不承诺对抗拥有宿主机权限的恶意租户。

## 微Link会把我的 API Key 放到公开仓库吗？

不会把仓库样例写成真实 Key；实际部署中的模型 Key、通道 Secret、OAuth 状态和登录态仍由部署者负责保护。SQLite、实例目录和日志可能包含敏感数据，不要上传公开仓库。

## FastAgent 是微Link的一部分吗？

FastAgent 是外部智能体运行时，负责实际对话、工具、Skill、MCP、记忆和定时任务；微Link负责 Web 控制面、用户/Bot 数据、Supervisor 生命周期和通道路由。两者的许可证和发布边界不同，见 THIRD_PARTY_NOTICES.md。

## Browserless 是必须的吗？

浏览器自动化、截图或 PDF 路径可能需要 Browserless；不使用这些任务时可以按部署版本将它设为可选。它使用 SSPL-1.0/商业许可，不应在项目文档中写成 MIT。

## 可以把微Link直接暴露到公网吗？

建议只暴露经过 TLS、访问控制和限流的 Web 入口。Supervisor、sandbox-runtime、Browserless 管理端口、SQLite、实例和 secrets 不应暴露公网。先读 deployment/production-hardening.md。

## 如何新增 Skill？

在 resources/skills/managed 下创建带 SKILL.md 的目录，写清依赖、权限、失败方式、外部副作用和许可证，并补测试/文档后提交 PR。不要把真实凭据或未核准的第三方素材放进去。

## 项目和华为 WeLink 有关系吗？

没有。本项目名为 微Link · 微灵 AI 助手，是独立开源项目，与华为 WeLink、腾讯微信/企业微信、飞书/Lark 或其关联公司没有隶属、授权、赞助或官方合作关系。

## 为什么项目以前叫 WeClaws？

微Link从公开的 WeClaws 项目演进而来，原始架构和许可证说明见 UPSTREAM.md。改名不改变 FastAgent、Browserless、Lark CLI、企业微信 SDK和托管 Skill 各自的许可。
