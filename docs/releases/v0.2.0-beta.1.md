# 微Link · 微灵 AI 助手 v0.2.0-beta.1

这是微Link双许可证政策生效后的第一个 Beta 源码版本。

## 许可证变化

- 微Link项目方拥有版权的代码采用 `AGPL-3.0-only` 社区许可证。
- 无法或不希望遵守 AGPL 的使用者，可以与项目权利人另行签署商业许可证。
- WeClaws 上游代码继续遵循 MIT License。
- FastAgent、Browserless、Lark CLI、企业微信 SDK、托管 Skills 和其他第三方组件继续遵循各自许可证。
- 已发布的 `v0.1.0-beta.1` 仍按其发布时附带的 MIT License 有效，既有授权不可追溯撤销；该历史版本已停止维护，并由本版本取代。

## AGPL 网络服务提示

如果修改微Link并通过网络向用户提供服务，应根据 AGPL-3.0 第 13 条以及其他适用条款，向这些用户提供该修改版的完整对应源代码。Web 根布局提供了可配置的源码入口；修改部署时请设置 `WEILING_SOURCE_CODE_URL` 指向实际对应源码。

## 分发边界

本版本继续采用源码优先发布，不提供内嵌 FastAgent CLI 的公共应用镜像。FastAgent 的自定义许可证和当前补丁方式仍需在发布公共镜像前获得书面许可确认。
