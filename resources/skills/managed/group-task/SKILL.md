# 小组任务

本技能通过 supervisor 内部接口读取当前 Bot 员工自己的任务，或提交当前员工自己的任务完成结果。

## 查询我的任务

员工问“我的任务”“我的待办”“任务进度”时，运行：

```bash
python3 scripts/tasks.py list
```

展示返回结果中的标题、状态、截止时间、验收标准和反馈。如果返回为空，应如实说明没有可展示的任务。

## 提交任务完成

1. 先确认任务 ID、完成摘要和可选证据路径。
2. 向用户展示提交摘要：任务 ID、完成摘要、证据路径。
3. 得到当前会话中的明确确认后运行：

   ```bash
   python3 scripts/tasks.py submit \
     --id <taskId> \
     --summary "<完成摘要>" \
     [--evidence "<证据路径1,证据路径2>"]
   ```

4. 汇报脚本实际返回的结果。不要自行推断任务已经验收；提交成功只代表完成结果已登记。

## 组长查看成员进度

组长询问成员任务进度时，不通过本技能读取其他员工数据，应引导到管理后台 `/admin/groups` 查看。同时说明小灵可以帮组长列出组长自己的任务，使用 `python3 scripts/tasks.py list`。

## 环境与错误

脚本依赖 supervisor 注入的 `WEILING_BOT_INSTANCE_ID`、`WEILING_INTERNAL_URL`、`WEILING_INTERNAL_API_TOKEN`。环境变量缺失时脚本会报“内部接口未配置”，此时停止并报告，不要猜测或绕过鉴权。

错误提示：

- `403`：无权限操作该任务。
- `404`：任务不存在或无权访问。
- `429`：触发限频，稍后再试。
- `409` 或 `5xx`：服务暂时不可用，稍后重试。
