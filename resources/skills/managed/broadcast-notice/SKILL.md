# 小灵群发通知

本技能只处理主动群发通知。发送前必须完成范围确认、内容预览和用户明确确认，任何一步缺失都不得调用发送脚本。

## 流程

1. 确认发送范围：
   - `group`：本组，由组长向自己的小组成员发送。
   - `all`：全员，仅已授权员工可使用。
   - `selected`：指定人员。要求用户提供员工姓名，并说明需要管理员在后台维护可群发名单；只能使用后台给出的 `botInstanceId` 映射，不能猜测或自行扩大目标。
2. 向用户展示拟发送全文和范围。范围用可理解的中文说明，例如“本组全部成员”“全员”“指定 3 人”；不要只展示技术参数。
3. 必须得到当前会话中的明确确认后，再运行：

   ```bash
   python3 scripts/broadcast.py \
     --text "<通知全文>" \
     --scope group|all|selected \
     [--targets "<botInstanceId1,botInstanceId2>"]
   ```

4. 向用户汇报脚本返回的投递结果。只报告实际返回的 `accepted`、`skipped` 或错误信息；不得把“请求已提交”说成“已经送达”。

## 禁止事项

- 未展示完整发送内容和范围、未得到明确确认前，禁止执行发送。
- 禁止自行扩大范围，例如从本组扩大到全员，或从已确认名单追加目标。
- 禁止在对话、日志、记忆或输出中暴露 `WEILING_INTERNAL_API_TOKEN`。
- 禁止猜测指定人员的 `botInstanceId`；无法从后台确认目标时，应停止并请管理员维护名单。
- 禁止把广播能力用于无关营销、骚扰或非员工主动授权的场景。

## 环境与错误

脚本依赖 supervisor 注入的 `WEILING_BOT_INSTANCE_ID`、`WEILING_INTERNAL_URL`、`WEILING_INTERNAL_API_TOKEN`。如果缺少必要环境变量，脚本会报“内部接口未配置”；此时不要尝试伪造地址或跳过鉴权。

脚本返回：

- `403`：当前员工无权限发送该范围。
- `429`：触发限频，稍后再试。
- `409` 或 `5xx`：目标或服务暂时不可用，稍后重试。
- 其他 HTTP 错误：原样向用户报告，不自行判定成功。
