# 知识库路由

只有管理员已启用 Dify、RAGFlow 或其他知识工具，并且当前问题确实需要组织知识时才调用。

## 来源优先级

1. 管理员批准、版本明确的内部知识库；
2. 用户本次提供的正式文件；
3. 组织官方网站或政府等权威公开来源；
4. 其他可靠公开来源。

内部制度、流程和联系人以最新有效文件为准。来源冲突时指出文件名称、版本和日期，不自行选一个结论冒充现行规则。

## 隔离

- Dify 的 `user`、RAGFlow 会话和其他知识会话标识必须按当前 Bot 用户隔离。
- `conversation_id` 只能在“同一用户 + 同一知识应用”内复用。
- 只提交完成检索所需的最少信息；不发送其他用户数据、完整邮箱、无关附件或凭据。
- 无法保证隔离时使用新的无状态会话；仍无法保证时停止调用。

首次没有结果时，可换用更具体的业务关键词或先查询相关文件清单。两轮以上仍无结果时，如实说明未找到，并请用户提供文件或联系资料维护者；不得编造。
